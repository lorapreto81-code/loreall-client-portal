## 2) Replique as Edge Functions
Puxe e recrie estas edge functions com o **mesmo código**:
- `topgestor-proxy` — proxy para a API TopGestor (login por email/celular/usuário, dados do cliente, atualizar dados, salvar email confirmado)
- `create-pix` — cria cobrança PIX via SyncPay
- `syncpay-webhook` — webhook do SyncPay com **lock atômico** (`UPDATE ... WHERE status='pending' AND renewed_at IS NULL RETURNING *`) e dedup por `provider_transaction_id`
- `payment-status` — polling de status de pagamento

## 3) Banco de dados (Lovable Cloud)
Aplique migração criando as tabelas com RLS + GRANTs:
- `payments` (com `provider_transaction_id UNIQUE`, `renewed_at`, `status`, cpf, valor, plano, customer_id, etc.)
- `confirmed_customer_emails` (customer_id, email, confirmed_at)
- `syncpay_plans`, `syncpay_subscriptions` (se usar)
- `referral_codes`, `referrals` (sistema Indique e Ganhe — bônus vai para o INDICADOR, não o indicado; requer status='ativo' e >3 dias restantes; senão fica `pending_referrer_renewal`)
- `system_config`

## 4) Secrets necessários
Peça ao usuário e salve via `add_secret`:

- `SYNCPAY_CLIENT_ID`, `SYNCPAY_CLIENT_SECRET`
- `SYNCPAY_WEBHOOK_SECRET`

## 5) Regras críticas a preservar (NÃO ALTERAR)
- Token TopGestor **somente no backend**, todo acesso via `topgestor-proxy`
- `POST /customers/{id}/renew` só pode ser chamado **após** `transaction.paid` confirmado no webhook
- Dedup obrigatório por `provider_transaction_id` — mesmo pagamento nunca renova 2x
- Login aceita **Email, Celular ou Usuário** (campo único inteligente)
- Ao cadastrar email, atualizar também no TopGestor via proxy
- Meus Dados pede apenas: Nome, WhatsApp e Email. **CPF só no fluxo do PIX**
- Botão "Otimizar acesso" só existe para clientes Warez (via Warez API), **não** via TopGestor
- Referral: +30 dias grátis para o indicador
- Visual: tema escuro por padrão, destaque dourado no "Indique e Ganhe", badge verde "Grátis" no +30 dias, banner promocional no login, credenciais de acesso no MyAccountSheet com ícones (usuário + cadeado) e gradiente destacado
